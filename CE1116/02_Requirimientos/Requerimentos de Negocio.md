## 📚 Idea/Concepto 
Especificación de lo que el sistema completo debe hacer y de las características que debe tener para satisfacer a usuarios y stakeholders.

## 📌 Puntos Claves (Opcional)
- Suelen hablar de metas como aumentar ventas, reducir costos, cumplir una norma o mejorar la experiencia del cliente.    
- Se definen antes que los requerimientos de sistema o de software y guían todas las decisiones posteriores.    
- Ayudan a priorizar funciones: se implementa primero lo que aporta más valor al negocio.    
- Si cambian los objetivos del negocio, normalmente cambian también estos requerimientos.
