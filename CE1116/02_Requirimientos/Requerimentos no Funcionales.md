## 📚 Idea/Concepto 
Propiedades de calidad y restricciones del sistema, como rendimiento, seguridad, disponibilidad, usabilidad o limitaciones técnicas.
## 📌 Puntos Claves (Opcional)
- Tiempo máximo de respuesta, número de usuarios concurrentes, tipo de cifrado, tiempo de disponibilidad, facilidad de uso
- No describen funciones nuevas, sino características de calidad que las funciones deben cumplir.
- Afectan la arquitectura y las decisiones tecnológicas del sistema.
- Si se descuidan, el sistema puede “hacer todo lo que debe”, pero resultar lento, inseguro o difícil de usar.
