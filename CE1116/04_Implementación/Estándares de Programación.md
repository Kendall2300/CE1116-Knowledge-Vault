## 📚 Idea/Concepto 
Conjunto de normas y pautas que definen cómo debe escribirse, formatearse y organizarse el código en un equipo u organización, para que sea legible, consistente, mantenible y de buena calidad.
## 📌 Puntos Claves (Opcional)
- Incluyen reglas sobre nombres de variables y funciones, indentación, comentarios, estructura de archivos, manejo de errores, etc
- Reducen errores y facilitan que diferentes desarrolladores entiendan y modifiquen el mismo código sin confundirse.
- Pueden ser propios del equipo o basarse en estándares reconocidos para ciertos lenguajes (por ejemplo, guías de estilo oficiales).
- Son una base para aplicar buenas prácticas como “código limpio” y para usar herramientas de análisis estático que detecten incumplimientos.
