## 📚 Idea/Concepto 
Lista clara de criterios que debe cumplir una historia o tarea para considerarse realmente terminada, por ejemplo codificada, probada, documentada y lista para liberar.

## 📌 Puntos Claves (Opcional)
- Incluye cosas como: código implementado, pruebas pasadas, revisión hecha y documentación mínima lista.
- Es un acuerdo de todo el equipo sobre qué significa “hecho”.
- Si una historia no cumple la DoD, no se considera terminada y no se debería mostrar como parte del incremento.
- Ayuda a mantener un nivel de calidad consistente en todas las funcionalidades.
