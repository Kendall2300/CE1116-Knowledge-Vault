## 📚 Idea/Concepto 
Proceso de recopilar y analizar datos sobre el comportamiento de una aplicación en tiempo real (métricas, logs, errores, tiempos de respuesta, disponibilidad) para detectar problemas, entender su rendimiento y asegurar una buena experiencia de usuario.
## 📌 Puntos Claves (Opcional)
- Suele medir métricas como uso de CPU y memoria, tiempo de respuesta, tasas de error, throughput y disponibilidad
- Se apoya en registros (logs), métricas y, en sistemas distribuidos, trazas para seguir el recorrido de las peticiones.
- Utiliza umbrales y alertas para avisar cuando algo se sale de lo normal (por ejemplo, aumento de errores o degradación de rendimiento).
- Es la base para la observabilidad: el monitoreo detecta los síntomas y la observabilidad ayuda a encontrar la causa raíz.
